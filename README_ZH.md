---

## ✨ 核心特性

- **自定义业务服务**: 标准化的服务开发规范与模板
- **事件驱动架构**: 模型事件、事件订阅与触发
- **外部 API 集成**: 第三方 API 对接与管理
- **拦截器**: 前后端拦截器，支持权限验证、参数校验、日志记录

## 🆚 社区版 vs 商业版

| 功能模块 | 具体能力 | 🟢 社区版 | 🔵 商业版 |
| :--- | :--- | :---: | :---: |
| **业务服务** | 常规服务运行时 | ✅ | ✅ |
| | 可视化编辑器 | ❌ | ✅ |
| | 跨 App 服务 | ❌ | ✅ |
| **事件机制** | 模型事件 | ✅ | ✅ |
| | 审批事件 | ❌ | ✅ |
| | AI 助理事件 | ❌ | ✅ |
| | Agent 工具事件 | ❌ | ✅ |
| | 自定义事件 | ❌ | ✅ |
| **外部集成** | 常规外部 API | ✅ | ✅ |
| **拦截器** | 前后端拦截器 | ✅ | ✅ |
